# SignFrame AI: attribution and release notes

**Portfolio package finalized:** 15 November 2026

**GitHub account:** Jean Aimé Iraguha / [Aime2k2](https://github.com/Aime2k2)

**Original implementation:** Tayyaba Ilyas / [tayyabastack/signframe-ai](https://github.com/tayyabastack/signframe-ai)

This repository folder preserves source code and research information
from the supplied upstream archive. The November 15 release adds
Windows launch instructions, a runtime file download helper, and
portfolio documentation. No original CNN source or original historical
model evaluation is claimed as independently authored by the maintainer.

The original public source has no license file in its root at the time
of this release. Attribution does not itself confer permission to
redistribute, modify, or relicense another author's work; obtain
appropriate permission where needed. The Sign Language MNIST dataset
has separate use terms and is not distributed here.

The pretrained CNN weights were checked using PyTorch CPU inference
and generated a (1, 24) output. A live webcam demonstration was not
run in this environment. No new accuracy is claimed.
